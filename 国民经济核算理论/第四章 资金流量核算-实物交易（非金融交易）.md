# 资金流量核算划分
- 非金融交易核算（实物交易）
- 金融交易核算


# **表结构与平衡关系**
**主栏**：交易项目；**宾栏**：机构部门

**来源与运用**：每个部门分“来源”与“运用”两列。
- **来源 (Source)**：记录收入、资金流入、负债增加（在金融篇）。
-  **运用 (Use)**：记录支出、资金流出、资产增加。

**两大平衡关系**：
    1. **纵向平衡（部门内部）**：部门内部来源合计 = 部门内部运用合计。
    2. **横向平衡（交易项目）**：各部门来源合计 = 各部门运用合计



# 初次分配（原始收入）

初次分配收入（原始收入）
## 计算公式
原始收入=增加值+国外收入净额
增加值总和为GDP
## GNI与GDP关系
GNI为国民总收入
GNI=GDP+国外收入净额
## 主要交易项目
劳动者报酬、生产净税额、财产收入、营业盈余


# 再分配
## 主要交易项目
- 所得税（收入税）
- 社会保障缴纳：五险一金
- 社会保障福利：退休金、报销医药费
- 社会补助/救济
经常转移：影响可支配收入 
资本转移：影响净金融投资
## 可支配收入
- 可支配收入=原始收入+经常转移收入-经常转移支出
- 可支配收入=原始收入+经常转移净额
# 收入使用核算（消费和储蓄）
可支配收入=消费＋储蓄
## 消费
## 储蓄
可支配收入用于最终消费后的余额
总储蓄=可支配收入−最终消费支出

原始收入=增加值-交易性分配
- 交易性分配遵循等价原则（劳动者报酬、生产税净额、营业盈余、财产收入）

可支配收入=原始收入-转移性分配
- 转移性分配遵循公平原则（社会保障，所得税（收入税），其他（捐赠、补贴、罚款））

最终消费支出=可支配收入-总储蓄
- 总储蓄是除了自己花钱买的东西就是总储蓄
