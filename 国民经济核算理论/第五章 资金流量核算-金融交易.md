# 金融资产的基本概念与分类

是经济资产的一种类型

## 金融资产分类
1. 货币黄金和特别提款权(SDRs)
2. 通货和存款
3. 债务性证券 (如债券)
4. 贷款
5. 股权和投资基金份额
6. 保险、养老金和标准化担保计划准备金
7. 金融衍生工具和雇员股票期权
8. 其他应收/应付款

## 对称性
金融资产和金融负债具有对称性。一方的金融资产必然是另一方的金融负债
**（货币黄金除外，货币黄金无负债）**

非金融投资与金融投资通过**净金融投资**相连接

# 金融交易核算原则
1. 权责发生制
2. 市场价格原则
3. 取净值原则
取净值指只记录金融资产的净增加和负债的净增加
（资金流量表记录的是净流量而非总流量）
4. 合并原则

# 资金流量表（金融交易）的结构与平衡

   **运用方（Use）**：记录**金融资产的净增加**（资金流出/占用）。

   **来源方（Source）**：记录**负债的净增加**（资金流入/来源）。
   
净金融投资=金融资产净增加−负债净增加
