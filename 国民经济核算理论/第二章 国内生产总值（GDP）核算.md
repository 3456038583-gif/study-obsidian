# 2.1 国内生产总值核算的基本问题
- 国民经济核算的是**经济生产**
	- **包含**：生产者提供给其他单位的货物或服务；生产者用于自身消费或投资的货物（如自产粮食）；自有住房服务（虚拟计算）。
	-  **排除**：住户内部提供的**无酬家务劳动**（如自己做饭、打扫卫生）不属于生产核算范围。
- 产出的分类
	- **中间产品**：在一个生产过程生产出来，然后又在另一个生产过程中被**完全消耗掉**或形态被改变的产品（例如面粉对于面包厂是中间产品）。
	-  **最终产品**：当期生产的被用于**最终消费、积累（投资）和出口**的产品。
- 国内生产总值
	- 从价值构成上看，国内生产总值是一国范围内各生产单位当期**增加值**的**总和**
	- 从实物构成上看，国内生产总值是一时期一国范围内各生产单位所生产的**最终产品**的价值总和
- GDP的三种核算方法
	- 生产法
	- 收入法
	- 支出法
	- 其中生产法和收入法是通过各产业部门增加值总计算，支出法是通过最终产品的使用去向计算。
# 2.2 增加值核算：生产法和收入法GDP
## 生产法
1. 增加值=总产出−中间投入
2. GDP=∑各产业部门增加值
## 收入法（分配法）
增加值=劳动者报酬+生产税净额+固定资本消耗（折旧）+营业盈余
## 总产出
指各生产单位在一定时期内所生产的全部货物和服务的**总价值**

## 总核算方法
总产出=∑产量×价格（生产者价格）

## 中间投入
又称中间消耗，指在生产过程中所消耗的**非耐用性**货物或服务的价值

## 增加值
总产出−中间投入

# 2.3 最终产品使用核算：支出法GDP

## 支出法计算方法
GDP=最终消费支出+资本形成总额+货物和服务净出口
- **最终消费支出** = 居民消费 + 政府消费
-  **资本形成总额** = 固定资本形成总额 + 存货增加（注意：存货增加计入投资/资本形成，而非消费）
- **净出口** = 出口 - 进口

## 支出法价格
支出法通常采用购买价格

## 最终消费率和资本形成率
• **最终消费率** = 最终消费 / 国内生产总值
• **资本形成率** = 资本形成总额 / 国内生产总值

# 2.4 GDP总体核算及其扩展

## GDP与GNI区别
- GDP反映了一时期一国各常住单位的生产成果，即在此期间生产活动所创造的价值。
- GNI用于反映一国从生产中所获收入总量的指标。

## GDP核算的局限性
- GDP核算没有考虑**资源环境与经济过程**的关系；
- GDP核算只给出了当期可用于最终使用的经济产品总价值 ，无法体现在经济产品和福利获得程度上的差别。
