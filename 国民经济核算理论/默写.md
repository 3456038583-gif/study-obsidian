# 常住单位的概念 
一个单位在一个国家具有一定的经济活动场所（厂房，住宅，建筑物），并且从事一定的经济活动，且超过一定的时期（一般以一年为单位），那么称该单位在此国家有经济利益中心，是这个国家的一个常住单位



# 改道概念+举例
改道就是改变经济交易发生的实际流程，按照不同于实际经济交易的途径进行的交易核算，
雇员所在单位向社会保障机构缴纳社会保障缴款。（这是改道前的流程）
分为先后两个过程。
先作为劳动报酬支付给就业者，再作为社会保障缴款由就业者支付给社会保障机构。



# 金融账户概念

金融账户是一国对外金融资产与负债所有权变更的所有经济交易。
包括资产与负债的产生与清偿。
金融资产是常住单位对非常住单位的债权
负债是常住单位对非常住单位的债务


# 国际收支核算含义，内容，记录方法

国际收支核算又称国际收支统计，以国际收支平衡表为核心，是对一国在核算期内的国际收支状况的系统记录。
从内容上看，国际收支核算记录了当期所有对外经济交易活动，并按照交易对象的性质对其进行划分。
从记录方法上看，国际收支核算借鉴性运用了会计借贷记账法，是对一国所有的对外经济交易活动的复式记录。
