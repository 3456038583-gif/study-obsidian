# 经济资产的定义与界定
- 所有权明确：由机构单位单个或联合使用所有权
- 经济利益：持有或使用该资产能产生经济效益

**属于经济资产**：已探明的可开采地下资源、购买的商誉、特别提款权（SDRs）。

**不属于经济资产**：公海、空气（除非密封作为工业气体）、未探明的矿藏、没有技术能力开采的资源、人的价值

# 资产的分类
## 非金融资产
- 生产资产（人力能达到）
固定资产、存货、贵重物品
- 非生产资产（人力无法达到）
自然资源（土地、矿藏）、合约、商誉、专利

## 金融资产

通货、存款、贷款、股票、债券、保险准备金

# 资产负债核算原则
1. 所有权原则
2. 估价原则：现期市场价格
3. 记录时间原则：权责发生制

# 核心指标与平衡关系
净值=全部资产（金融+非金融）-负债
国民财富计算方法
1. 结构法：国内各机构部门净值之和
2. 资产法：国内非金融资产+对外金融净资产

**国内金融资产不计入国民财富**，只有**非金融资产**和**对外净资产**才构成国民财富。

# 积累核算：存量变化的原因

• **资产其他物量变化**：非交易因素引起的。如：发现新矿藏、**灾害损失**、被政府无偿没收、债权人单方面注销坏账。

• **重估价（持有损益）**：仅由**价格**变动引起的价值变化。分为中性持有损益（随通胀变动）和实际持有损益
